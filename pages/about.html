关于这个博客

这是一个极简的静态博客系统，纯 HTML/CSS/JS 构建，无构建工具，无依赖安装。

设计理念

  • 零依赖 — 不需要 npm、webpack、或任何构建步骤
  • 双存储 — 支持 GitHub Pages 和本地服务器两种模式
  • 离线可用 — CDN 失效时自动回退到本地 JS 文件
  • 可扩展 — 主题、存储后端均可配置

技术栈

  • marked.js — Markdown 解析
  • KaTeX — 数学公式渲染
  • Mermaid — 图表渲染
  • Prism.js — 代码高亮
  • Python http.server — 本地存储服务器（零依赖）

功能特性

  • Markdown 写作，支持 LaTeX 数学公式和 Mermaid 图表
  • 编辑器工具栏，快速插入常用模板
  • 图片粘贴/拖拽上传
  • 草稿自动保存
  • RSS 订阅
  • 7 套主题（含小马宝莉角色配色）
  • CDN 离线回退
  • 本地密码认证

快速开始

方式一：本地服务器

python3 server.py
# 浏览器打开 http://localhost:8080

方式二：GitHub Pages

将仓库推送到 GitHub，在 Settings → Pages 中配置部署源即可。
