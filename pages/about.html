Minimal Blog.

纯 HTML/CSS/JS 构建的静态博客系统。零依赖、零构建、双存储、多主题。开箱即用。

快速开始 查看博客

Features

一切从简，但该有的都有

✍

Markdown 写作

完整的 Markdown 支持，配合 KaTeX 数学公式和 Mermaid 图表，从笔记到论文都能写。

💻

双存储模式

GitHub Pages 和本地服务器自由切换。编辑器自动检测，无需手动配置。

🎨

7 套主题

暗色、亮色、护眼绿，加上小马宝莉角色配色。CSS 变量驱动，切换即时生效。

📤

图片上传

粘贴或拖拽图片到编辑器，自动上传并插入 Markdown 语法。支持 Base64 和服务器存储。

🔄

CDN 离线回退

CDN 挂了？自动回退到本地 JS 文件。内网部署也能正常使用所有功能。

🔒

密码认证

本地服务器支持可选的密码保护。Fine-grained Token 管理 GitHub 访问权限。

Quick Start

两种方式，一分钟启动

▶ 本地服务器

cd blog
python3 server.py

# 带密码认证
python3 server.py --password mysecret

🌐 GitHub Pages

git push origin main

# 在 GitHub Settings → Pages
# 选择部署分支和目录
# 完成
