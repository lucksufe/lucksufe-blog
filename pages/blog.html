Features

一切从简，但该有的都有

✍

内置编辑器

自带 Web 编辑器，内置 Markdown 格式、LaTeX 公式、Mermaid 图表模板，点击即插入，无需记语法。新手也能立刻上手写作。

💻

双存储模式

GitHub Pages 和本地服务器自由切换。编辑器自动检测，无需手动配置。

📊

公式 & 图表渲染

内置 KaTeX 数学公式和 Mermaid 图表引擎。LLM 生成的 LaTeX 公式、流程图、时序图，直接复制粘贴即可渲染保存。

📤

图片上传

粘贴或拖拽图片到编辑器，自动上传并插入 Markdown 语法。支持 Base64 和服务器存储。

🔄

CDN 离线回退

CDN 挂了？自动回退到本地 JS 文件。内网部署也能正常使用所有功能。

🔒

密码认证

本地服务器支持可选的密码保护。Fine-grained Token 管理 GitHub 访问权限。

Quick Start

两种方式，一分钟启动

🌐 GitHub Pages（推荐）

零依赖、开箱即用。最简单的发布方式。

git push origin main

# 在 GitHub Settings → Pages
# 选择部署分支和目录
# 完成

▶ 本地服务器

cd blog
python3 server.py

# 带密码认证
python3 server.py --password mysecret
