Use Cases

不只是博客。从个人笔记到团队文档，一个系统覆盖多种场景。

✍

写博客

最直接的用法。Markdown 写作、标签分类、全文搜索、RSS 订阅，该有的都有。写完即发布，零构建流程。

🤖

存储 LLM 对话

ChatGPT、Claude 生成的回答经常包含公式、代码、图表。直接复制粘贴到编辑器，KaTeX 和 Mermaid 自动渲染，比截图更清晰、可编辑、可检索。

📊

公式 & 图表素材

需要把公式或流程图放进 PPT、论文、文档？在编辑器里写好，渲染效果截图即可。比手画快，比 LaTeX 编译方便。

📚

个人知识库

按标签组织笔记，全文搜索快速定位。比 Notion 轻，比纯文本文件结构化。所有数据都是 JSON，随时可以迁移。

💻

项目文档

代码高亮支持 Python、JavaScript、Bash、C/C++ 等语言。适合写 API 文档、技术方案、开发笔记。密码保护可限制访问范围。

🎓

教学课件素材

数学公式、化学方程式、流程图、时序图——教学中常用的复杂内容，写好渲染后截图插入课件或试卷。

👥

团队内部博客

本地服务器加密码保护，只对团队成员开放。发布周报、技术分享、会议纪要，比邮件好找、比聊天软件好整理。
