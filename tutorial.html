使用教程

1. 启动博客

本地服务器模式

# 进入博客目录
cd blog

# 启动服务器（默认 8080 端口）
python3 server.py

# 带密码认证
python3 server.py --password mypassword

# 自定义端口
python3 server.py 3000

然后浏览器打开 http://localhost:8080 即可访问博客。

GitHub Pages 模式

将代码推送到 GitHub 仓库，在 Settings → Pages 中选择部署分支和目录。编辑器会自动检测并切换到 GitHub 模式。

2. 写文章

打开 编辑器页面，你会看到：

  • 工具栏 — 三个下拉菜单：Markdown、数学公式、图表
  • 输入区域 — 标题、标签、摘要、正文
  • 预览按钮 — 实时预览渲染效果

使用工具栏

点击工具栏上的按钮，选择模板即可插入到光标位置。例如：

  • 点击 数学公式 → 分式，插入 $\frac{a}{b}$
  • 点击 图表 → 流程图，插入 Mermaid 流程图模板
  • 选中文本后点击 粗体，自动包裹 **文本**

3. 数学公式

支持两种定界符：

行内公式

用 $...$ 包裹：
爱因斯坦的质能方程 $E = mc^2$ 是物理学中最著名的公式之一。

块级公式

用 $$...$$ 或 \[...\] 包裹：

$$\int_{0}^{\infty} e^{-x^2} \, \mathrm{d}x = \frac{\sqrt{\pi}}{2}$$

4. Mermaid 图表

用 ```mermaid 代码块包裹图表定义：

流程图

    A[开始] --> B{判断}
    B -->|是| C[执行]
    B -->|否| D[结束]

时序图

sequenceDiagram
    participant U as 用户
    participant S as 服务器
    U->>S: 请求
    S-->>U: 响应

5. 代码高亮

用三个反引号包裹代码块，指定语言名称：

def hello():
    print("Hello, Blog!")

支持的语言包括：Python、JavaScript、C/C++、Bash 等。

6. 图片上传

在编辑器中可以直接：

  • 粘贴 — 复制图片后 Ctrl+V
  • 拖拽 — 将图片文件拖入编辑区

图片会自动上传并插入 Markdown 图片语法。

7. 草稿保存

编辑器每 30 秒自动保存草稿到浏览器本地存储。下次打开同一文章时会提示是否恢复。

8. 主题切换

点击页面右上角的主题按钮，可切换：

  • 🌙 暗色 — 默认深色主题
  • ☀️ 亮色 — 浅色主题
  • 🌿 护眼绿 — 柔和的绿色主题
  • 🦄 紫悦 — 紫色主题（小马宝莉）
  • 🌈 云宝 — 青蓝色主题
  • 🦋 柔柔 — 粉色主题
  • 💎 珍奇 — 淡紫色主题

9. RSS 订阅

博客自动生成 rss.xml，可以用任何 RSS 阅读器订阅。
