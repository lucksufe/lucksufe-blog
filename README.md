# Blog

极简静态博客。纯 HTML/CSS/JS，无构建工具，无依赖安装。

## 使用模板

如果你想要一个干净的博客模板，请访问 **[_blog](https://github.com/lucksufe/_blog)** — 不含任何数据的开箱即用版本。

```bash
git clone https://github.com/lucksufe/_blog.git
cd _blog
python3 server.py
```

## 关于本仓库

本仓库是开发和数据分支，包含实际博客内容和完整提交历史。日常使用和 Vercel 部署基于此仓库。
