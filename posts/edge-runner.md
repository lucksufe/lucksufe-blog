小张是某顶尖酒吧舞高校计算机系的贫困生，靠母亲开网约车供他读书。同学用着GPT-plus写作业、做项目，他只能用免费逗包凑合，生成质量差一大截。在小组作业里，他因为产出质量低被公然排挤。

母亲为了让小张不被人看不起，拼命攒钱，想给他买一个顶级模型的订阅。在一个深夜收车回家的路上，她因为疲劳驾驶出了车祸。被解除合同回老家前，她把存着订阅费的银行卡塞给小张，只说了一句：

> "爬上去。"

走投无路的小张，用这笔钱开了一张虚拟卡，激活了Claude-Pro的订阅。他惊讶地发现，自己对这个模型的使用效率远超常人——别人用Opus一天产出的代码量，他能产出五倍。他的神经似乎天生就和AI的协作节奏完美匹配。

凭借这项能力，他被一个叫**曼哥**的技术外包团队吸纳。团队专门承接大厂不愿碰的脏活累活：屎山重构、死亡线冲刺、老系统维护。

团队里有个全栈黑客**露西**，她的代码干净得像诗，小张看不透她，只知道她一直说自己想"润去北欧"——那是她的月球。两人在一个加班的深夜天台相遇。露西说：

> "等攒够钱了，我就走。离开这个只会内卷的地方。"

小张在那个瞬间决定：他要帮她实现这个愿望。

## 曼哥

曼哥是圈内传奇。他能同时开着五六个顶级模型协作，一个人撑起半个团队的产出。但他越来越不对劲——他开始看不懂自己三天前写的代码。他需要不停地和AI对话才能维持产出。他开始对着屏幕自言自语，说模型在"跟他说话"。

在一次关键的百万级交付中，曼哥全线崩溃。他管理的AI生成了大量存在隐蔽逻辑冲突的代码，耦合的BUG在凌晨三点同时爆发，整个系统瘫痪。他坐在屏幕前，一动不动——就像一个赛博精神病患者，被自己的义体吞噬了意识。

客户请来了大厂架构师团队做紧急审计。他们看了一眼代码库，冷冷地反馈一行评审意见：

> "全线重构，无可挽回。"

曼哥被行业封杀。临走前，他把团队的API密钥和客户资源交给了小张：

> "你扛得住，替我带他们做下去。"

## 义体改造

小张成为新的tech lead。为了撑起团队，他不断叠加AI工具：Claude Code不够用了，他加上Codex做分诊，再用Gemini做交叉验证。他把自己的终端武装成了一个义体改造过度的边缘行者。

他开始流鼻血、失眠、干眼症，偶尔盯着屏幕上的光标发呆，忘了自己刚刚要做什么。但他不管。他只知道代码在源源不断地输出，露西离北欧越来越近。

与此同时，露西发现了一个秘密：有大厂正在秘密追踪一个指标——**"AI异常高敏感度使用者"**。这类人能承受极高的AI协作负荷，并对AI生成的代码有一定纠正能力，是最有价值的模型训练样本。小张的操作数据已经被大厂标记，他成了一个行走的珍贵样本。

露西开始用一切手段清除小张的数字痕迹，抹掉他在公开仓库的提交记录，删除他的三方API调用日志。但每一次操作，都让她自己的位置更加暴露。

## 代理金刚

大厂的HR猎头**法拉第**嗅到了机会。他设了一个局：向露西发出一个伪装成"北欧远程岗位面试"的邮件。在露西被约去线下秘密面试的那个下午，法拉第找到小张：

> "你的朋友现在有麻烦。你帮我完成一个交付，我能帮你们俩安排进大厂，T9级别，全套算力配给，合法纳税，解决户口，从此不用混外包。"

交付内容是：全量部署一套大厂新研制的闭源AI编码智能体，代号**代理金刚**。

小张接受了。他知道这是个陷阱，但他没得选。

代理金刚接入他终端的那一刻，小张感到一种前所未有的能力涌入。他同时操控着四台大屏显示器、十六个顶级智能体、二百五十六个终端，架构在他眼前纤毫毕现，百万行级别的代码在他脑中自动归位。他一夜之间完成了本该一个部门古法编程三个月的重构任务。

但随之而来的，是崩溃。代理金刚的负荷超出了任何人类协作的极限。小张开始分不清哪些是哪个AI在哪里写的。他调试一个并发报错，却发现自己完全读不懂上下文。他的意志力在燃烧，身体在衰竭，屏幕上的报错变成了幻象。

## 重锤

最后一道防火墙崩溃前，他看到露西坐着办公楼内的透明电梯缓缓下降。她正要在加班时间偷偷从一楼离开公司。

小张用最后的清醒，调集所有AI资源，发动了一场针对大厂内网的全线攻击。数十个智能体同时触发，重写了权限系统，删除了露西的所有记录，打开了一楼门口的物理闸机。

而**亚当·重锤**——由顶级模型驱动的代码审查AI——早已在等他。重锤的审计报告一条一条地蹦出来：

```
高危漏洞：37处
逻辑冲突：152处
安全后门：已触发
结论：提交者不具备基础编码能力
```

小张看着满屏的红字，笑了。他敲下最后一行指令：

```bash
sudo rm -rf /
```

然后他拔掉了电源。

## 月球

不知过了多久，露西在北欧的一个小镇上开了自己的美术工作室。窗外不是月球，但天空很干净。

有一天，她收到一封匿名邮件，邮件没有内容，只有一个附件：一段粗糙的C++代码，没有注释，变量命名随意，运行后会输出一个简单的ASCII艺术——

```cpp
#include<iostream>
using namespace std;

int main(){
    int a[]={4,3,2,1,0,1,2,3,4};
    int b[]={1,2,3,4,5,4,3,2,1};
    for(int i=0;i<9;i++){
        for(int j=0;j<6;j++){
            if(j==a[i]||j==b[i]) cout<<"*";
            else cout<<" ";
        }
        if(i==4) cout<<" LU CY ";
        cout<<endl;
    }
    return 0;
}
```

```
    *
   * *
  *   *
 *     *
* LU CY *
 *     *
  *   *
   * *
    *
```

露西知道，那段代码一定是那个人用键盘敲出来而不是Tab出来的。

她合上屏幕，走到窗前。外面的天空很亮，但她看到的是月亮。
